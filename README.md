## 📖 简介
* 基于 [bylkuse/astrbot_plugin_help_typst](https://github.com/bylkuse/astrbot_plugin_help_typst) 进行重度开发的插件菜单
* 把插件菜单、事件钩子、函数工具、过滤器列表渲染成友好界面，智能组织节点和分组，并附上丰富的元信息。
* 基于 typst 渲染实现，轻量、灵活、高效，你可以使用 typst 语法修改、构建属于自己的渲染模板（WIP）

## 🛠️ 安装

在astrbot的插件市场搜索astrbot_plugin_helps，点击安装即可

## ⚙️ 命令表

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `helps [关键词]` | `帮助`、`菜单` | 显示指令菜单，可使用关键词搜索 |
| `plugin <插件名>` | `插件` | 显示单个插件的完整分析 |
| `hooks [关键词]` | `钩子`、`事件`、`监听器`、`events` | 显示事件钩子列表，可使用关键词搜索 |
| `tools [关键词]` | `工具` | 显示函数工具列表，可使用关键词搜索 |
| `filters [关键词]` | `过滤器` | 显示过滤器详情，可使用关键词搜索 |
